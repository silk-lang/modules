Latest run of each app

Lower is better on every chart. Bars are the median over a session's runs; the thin line spans the fastest and slowest run. Each app shows its most recent session on the chosen machine.

In the CPU suite Electron paces its frames at 120 a second and rasterizes in software, so its frame time is pacing. Compare CPU per frame for Electron. Silk and the Rust apps run frames back to back on a fake clock, so idle CPU is not shown for them.

Start-up, phase by phase

Each app's start, launch to its first frame, as phases on its threads: the median of each phase over the launches of the app's latest session with a timeline. Solid bars are the path to the first frame; hatched bars run beside it. Each app shows a warm start (the median of the launches after the first) and a cold start (caches deleted, files dropped from the file cache) on one shared time axis.

In the CPU suite there is no window and no GPU, so this is the CPU work only. Silk UI's windowless bench reports its first frame as one style, layout and text phase, and does not trace what comes after it. Grey "untraced" time is time no phase mark covers.

Progress over time

One point per session. A label says what changed in that session.

What each metric means
Warm start
Launch to the first frame with content on screen, median of the runs after the first. Silk hides its window until it can draw, so its first shown frame is already content.
Cold start
The same, with the app's GPU, shader and code caches deleted and its files dropped from the operating system's file cache.
Frame time
Wall time of a driver step divided by its frames. In the GPU suite, run uncapped where the app allows it.
CPU per frame
CPU time of the whole process tree, all threads, over the step, per frame.
Memory
At each mark, with the app paused. Linux: proportional set size of the process tree. macOS: physical footprint, what Activity Monitor shows. Electron counts its GPU, renderer and utility processes.
Idle CPU
Percent of one core while the app has nothing to do.
p99 frame interval
The app's own time between frames at the 99th percentile, GPU suite only: the frames that would miss a deadline at 120 Hz.
